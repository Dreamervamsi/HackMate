# Docker Validation Containers

This directory contains Docker configurations for code validation environments.

## Overview

The validation containers provide isolated environments for testing and validating code generated by the HackMate agents. Each container is configured with:

- Resource limits (CPU, memory)
- Network isolation
- Security hardening
- Language-specific testing tools

## Available Containers

### Python Validator (`Dockerfile.python`)

- **Base Image**: `python:3.11-slim`
- **Installed Tools**:
  - `pytest` - Testing framework
  - `pytest-cov` - Coverage reporting
  - `pytest-timeout` - Test timeout handling
  - `flake8` - Code linting
  - `mypy` - Static type checking
  - `black` - Code formatting
  - `isort` - Import sorting
  - `pylint` - Code analysis
  - `bandit` - Security linting
  - `safety` - Dependency vulnerability scanning

## Usage

### Build the containers

```bash
cd backend/docker/validation
docker-compose build
```

### Run containers

```bash
docker-compose up -d
```

### Stop containers

```bash
docker-compose down
```

## Security Features

- **Network Isolation**: Internal bridge network with no external access
- **Resource Limits**: CPU and memory constraints to prevent resource exhaustion
- **Non-root User**: Containers run as non-privileged user
- **Read-only Filesystem**: Prevents unauthorized modifications
- **No New Privileges**: Additional security restriction

## Integration with HackMate

The validation agents in `backend/src/agents.py` automatically use these Docker containers for:

1. **Test Generation**: Creating comprehensive tests for generated code
2. **Code Validation**: Running tests in isolated environments
3. **Bug Detection**: Identifying syntax, logical, and runtime errors
4. **Auto-fix Loop**: Automatically fixing bugs up to 2 times

## Configuration

### Resource Limits

- **CPU**: 1.0 core (limit), 0.5 core (reservation)
- **Memory**: 512MB (limit), 256MB (reservation)
- **Timeout**: 30 seconds per validation run

### Network

- **Type**: Internal bridge network
- **Access**: No external network access for security

## Troubleshooting

### Docker not running

```bash
# Check Docker status
docker --version

# Start Docker daemon (if needed)
# On Windows: Start Docker Desktop
# On Linux: sudo systemctl start docker
```

### Container build failures

```bash
# Rebuild without cache
docker-compose build --no-cache

# Check build logs
docker-compose build --progress=plain
```

### Permission issues

```bash
# Fix file permissions on host
chmod -R 755 backend/docker/validation
```
